FAQ

Amazon Vendor Analytics：真实经营决策中的常见问题

Amazon Vendor 与 Seller 分析有什么区别？

Vendor 是向 Amazon 批发，Seller 是平台零售。Vendor 需要追 PO、发货和批发付款，并用零售报表理解需求，两种收入不能互相替代。

Vendor Central 零售额为什么比回款高？

零售额是 Amazon 向消费者销售，回款对应我方批发发票并受扣款、时间影响。应使用发票与付款证据解释，不能直接拿两个总数相减。

能调查 Amazon Vendor Shortage 扣款吗？

可把提供的扣款记录与 PO、发货及收货证据汇集，比较争议数量并找出缺证。本场景支持复核，不裁定申诉成立，也不自动提交申诉。

Vendor Fill Rate 应该怎么算？

先定义比较下单、确认、发货还是收货数量，固定周期和分母，不能混不同阶段。缺收货证据时，不能给出已验证的收货满足率。

Vendor Forecasting Report 能支持补货吗？

可以，把同周期预测与现货、预计收货比较。mean、p70、p80、p90 是不同需求情景，不能相加；分时计划还需要收货日期。

公开 Schema 已包含 Chargeback 和 Remittance 吗？

公开 Vendor 预览列出了运营与零售表，不能据此推定已覆盖扣款或付款通知。回款分析前需确认工作区实际报表，或提供授权账单。
