官方 OAuth

不获取平台密码、也不模拟浏览器登录

只读数据访问

Hologrow 不会修改广告、价格、Listing、库存或订单。只读数据，没有操作。

撤销、隔离与删除

平台数据授权可随时撤销，各数据分区保持隔离；结束服务并撤销数据授权后，相关数据将在30天内彻底删除。

状态可见、信息最小化

Hologrow 只接收 AI 客户端发送给 MCP 工具的请求；无法读取客户端未发送的对话、账号或其他信息。

不绕过平台，所有数据均走官方认证的授权形式 · 按平台要求合规、无需共享密码、不模拟登录

FAQ

电商跨平台数据整合：真实经营决策中的常见问题

电商分析如何合并 Amazon 与 Shopify 数据？

通过获批商品映射和统一币种、时区、收入定义对齐订单。保留来源合计并解释折扣、退款、税、运费调整，不强行让数字相等。

Shopify 与 Amazon 看板为什么对不上？

订单状态、日期边界、税或退款处理可能不同。先比较相同业务事件；未统一前，口径差异可能看起来像增长差异。

能做跨平台商品利润报表吗？

有商品映射、成本和各渠道扣减时可以。共享花费需明确分摊，未知成本单列；销售可比较，不代表利润已可比较。

Hologrow 数据能用于 Looker Studio 或 Google Sheets 吗？

配置好的导出、仓库或外部工作流可为目的地准备数据，需要确认实际连接方式和刷新流程。这里是组合工作流，不承诺所有 BI 工具都有原生连接。

广告归因收入能加进电商销售额吗？

不能。广告系统认领的订单可能已计入店铺销售。应将归因与订单收入并列，说明窗口和重叠，不能相加成更大的销售总额。

跨平台整合会自动合并客户身份吗？

不会。本场景聚焦商品、渠道、日期等适当粒度的经营指标。个人身份解析需要独立合法数据、权限和验证方法，不按相似姓名或邮件自行推断。
