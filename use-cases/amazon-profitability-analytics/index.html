FAQ

Amazon Profitability Analytics：真实经营决策中的常见问题

如何按 ASIN 计算 Amazon 卖家利润？

以明确折扣、退款处理的商品收入为起点，减平台费用、履约成本、可归属广告与生效商品成本；共享费用需注明分摊规则。未涵盖管理费和税等项目时，贡献利润不等于会计净利润。

为什么 Amazon 销售增长，利润反而下降？

新增订单可能来自不同商品组合、更高获客成本、更深折扣或更多退货。对可比周期建立金额变化桥，检查哪些扣减涨得比销售快，不能只凭营收推测原因。

ACoS 很低，就说明商品赚钱吗？

不一定。ACoS 不含商品成本、履约费用或退款。应在兼容商品和周期范围内，把广告费与广告前可用贡献利润比较；混合活动做 ASIN 结论前还需要有依据的分摊。

Amazon FBA 利润计算器与实际利润分析有什么区别？

计算器按假设价格和费用估算单件经济性；实际分析使用已发生订单、结算、退款与成本版本。前者用于计划，后者用交易证据解释结果。

部分 SKU 没有成本，还能算利润吗？

将这些 SKU 放进成本不完整清单，展示销售和已知扣减，但不标为最终利润。使用经批准估值时应标注版本与日期；缺失成本不能默认为零。

可以在修改 Amazon 售价前推演降价影响吗？

可以，前提是明确需求、费用、折扣规则与成本假设。比较各价格的单件贡献，并显示保住利润需要的销量；情景不预测顾客反应，也不修改 Listing。
