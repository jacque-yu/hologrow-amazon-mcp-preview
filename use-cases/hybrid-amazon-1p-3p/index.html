FAQ

Hybrid Amazon 1P + 3P：真实经营决策中的常见问题

Amazon 1P 与 3P 混合模式是什么？

企业同时采用 Vendor 批发和 Seller 平台零售。分析应比较各路径经济性和约束，同时保留不同收入事件、费用与回款时间。

Vendor 零售额能直接加 Seller 销售额吗？

粒度兼容时可作为明确标记的零售需求视图。公司收入应按会计政策使用已确认批发收入与 Seller 收入，不能用 Vendor 零售售出替代。

怎么比较 1P 和 3P 哪个更赚钱？

统一商品、单位和币种后，分别计入批发扣减或平台费用、广告、退货，并考虑现金节奏与供给承诺。不能仅凭利润率高低决定路径。

能证明 3P 蚕食了 Vendor 销售吗？

不能。此消彼长也可能来自库存、价格或促销变化。工作流识别模式与替代解释，因果结论需要合适实验或更强证据。

Vendor 与 Seller 的共享库存怎么分？

对同一主 SKU 比较已确认承诺、预期贡献、需求与可售到货时间，在约束下推演可行方案，再由授权负责人批准分配。

1P/3P 看板需要什么数据？

需要 Vendor PO 与零售报表、Seller 订单与费用、统一商品映射、成本和授权批发收入记录。涉及供给分配或现金情景时，还需供给与付款计划。
