FAQ

Amazon Reconciliation：真实经营决策中的常见问题

为什么 Amazon 回款和 Seller Central 销售额不一致？

销售可能按下单或发货统计，而回款结算包含费用、退款、调整，周期也不同。应先核对单一币种与结算周期，再把对应到账和银行记录比较。

Amazon Settlement Report 对账要看哪些字段？

可从 settlement_id、订单 ID、金额类型、金额描述、金额及到账日期建立证据链，保留正负号和来源行键。不是每笔费用都有订单 ID，账户级扣费需要单独分类。

Amazon 对账能发现漏退款吗？

可标记未见对应退款的退货记录，或未匹配订单的退款。认定漏退款前，应检查事件时间、部分退款与数据完整性；实物退回与财务退款是两个事件。

回款对账中，准备金和调整怎么处理？

需要对应来源明细或授权账单证明，已确认准备金应与费用分开。若现有报表不能解释原因，应保留未解释差額，不能默认差额全是准备金。

可以自动生成并过账 Amazon 会计分录吗？

本场景准备匹配证据和异常分类建议。生成或过账分录需要另行配置的会计集成、获批科目映射及复核；这里的 Hologrow 工作流不写入来源账户。

多站点、多币种的 Amazon 回款怎么对账？

匹配键保留站点、币种和结算 ID，先按原币对账。合并报告时再按明确汇率政策折算，否则汇差可能被误认为少回款。
