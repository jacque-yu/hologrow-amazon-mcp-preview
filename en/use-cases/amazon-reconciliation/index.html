FAQ

Amazon Reconciliation: questions from real operating decisions

Why does my Amazon payout differ from Seller Central sales?

Sales are measured on an order or shipment basis, while payouts include settlements of fees, refunds and adjustments over a different period. Reconcile one currency and settlement first, then compare its deposit with the bank record.

Which Amazon Settlement Report fields help with reconciliation?

Settlement ID, order ID, amount type, amount description, amount and deposit date provide a starting trail. Preserve signed amounts and source row keys. Not every fee has an order ID, so account-level charges need their own classification.

Can Amazon reconciliation identify missing refunds?

It can flag return records without a corresponding observed refund, or refunds without matched orders. Check event timing, partial refunds and source completeness before calling a refund missing. A physical return and a financial refund are different events.

How should I handle reserves and adjustments in payout reconciliation?

Use the specific source lines or authorized statements that explain them. Keep documented reserves separate from fees. If the available report does not identify the reason, retain an unexplained balance instead of automatically classifying the gap as a reserve.

Can this create Amazon accounting journal entries automatically?

This use case prepares matching evidence and proposed exception classifications. Journal creation or posting requires a separately configured accounting integration, approved account mapping and review. Hologrow does not write to the source account in this workflow.

How do I reconcile multiple Amazon marketplaces and currencies?

Keep marketplace, currency and settlement IDs in the matching key. Reconcile local-currency amounts first. Convert for consolidated reporting only with a stated exchange-rate policy; otherwise exchange differences can look like missing payouts.
