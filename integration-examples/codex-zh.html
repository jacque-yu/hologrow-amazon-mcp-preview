06 / 安全与控制

Codex 只读数据，控制权在你手中。

授权数据连接，账户操作仍由你决定。

连接凭据加密保存

Hologrow 加密保存源连接凭据，AI 访问范围跟随授权连接的 Hologrow 用户。

源数据访问保持只读

通过 Hologrow 分析已同步记录，不修改出价、预算、商品或订单。执行前请复核 AI 结论。

随时撤销访问

不再需要客户端访问数据时，可在 AI Platforms 管理并撤销对应授权。

AI 客户端与模型提供方有各自的权限和数据政策。Hologrow 的只读边界适用于其提供的工具。

07 / 常见问题

Codex 集成常见问题

连接方式、实际工作流程，以及首次分析前需要核实的内容。

Hologrow 的 Codex MCP 集成能做什么？

它让 Codex 只读访问已同步的电商与营销数据。你可以让 Codex 检查可用表、分析变化，并据此制作报告或工具。

需要自己为 Codex 搭建 MCP server 吗？

不需要。Hologrow 提供托管 MCP 服务，在桌面端添加 Streamable HTTP 地址并授权即可；数据源账户仍需先在 Hologrow 连接。

桌面端连接需要 API key 吗？

文档中的 Codex 桌面端流程是在保存 MCP 后点击 Authenticate，bearer token 和 header 留空。客户端配置不同时，以完整指南为准。

Codex 可以生成看板而不只是文字回答吗？

可以让 Codex 在工作区创建报告文件、图表或分析工具。Hologrow 提供数据，产物格式及托管方式取决于客户端与项目配置。

生成的看板会自动刷新吗？

仅连接 MCP 不会让看板自动刷新。Hologrow 负责数据同步；看板刷新、定时执行和部署需独立配置，并保证客户端或应用运行。

如何核对 Codex 的计算？

要求输出来源表、日期范围、币种、行粒度与筛选条件。去重订单数与商品行数应分别检查，比较前先核实缺失日期。

Codex 项目能通过 Hologrow 修改广告吗？

不能。Hologrow MCP 读取已同步数据，不修改出价、预算、商品或订单。Codex 对本地文件的修改由客户端权限单独管理。

团队工作区里由谁授权 Codex？

工作区规则可能要求 owner 或管理员先添加 MCP 连接，再开放给成员。团队启用前，请核对 Codex 指南与工作区权限。
