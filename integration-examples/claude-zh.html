如何把 Amazon 接入 Claude？+

在 Hologrow Integrations 授权 Amazon Seller，并在 Data Explorer 查看同步状态。在 Claude 网页版或桌面版打开 Settings → Customize → Connectors → Discover，搜索 hologrow 并授权。先验证已连接的平台，再开始分析。

需要写代码或自己部署 MCP 吗？+

无需自己部署服务。Claude 网页版和桌面版通过托管连接器完成授权。工作区需要允许使用连接器；Team 或 Enterprise 可能需要管理员先添加 Hologrow。

Claude Code 也能用吗？+

可以。Claude Code 使用 Hologrow 托管 MCP 地址和 AI Platforms 中创建的 MCP 密钥，与网页版和桌面版的连接方式不同，请按文档中的 Claude Code 步骤设置。

连接 Seller Central 后就有 Amazon Ads 数据吗？+

Amazon Seller、Vendor 与 Ads 是不同数据源。分析广告花费、关键词或归因销售额时，需要另行连接 Amazon Ads。可用范围取决于授权账户、站点和报告权限。

能一起分析 Amazon、独立站和 Google 数据吗？+

相关数据源与周期可用时可以。本页以 Shopify、Google Ads 和 GA4 补充 Amazon 数据。Shopify 覆盖正在扩展，请先确认账户内可用表，再对齐币种、业务日期和商品映射；广告归因销售额与订单销售额应分开呈现。

Shopify、Meta Ads 等其他平台支持了吗？+

不同数据源的覆盖正在扩展。文档列出的持续同步来源包括 Amazon Seller、Vendor、Ads、Shoplazza、Google Ads、GA4 和 Search Console。Shopify、Meta Ads、Amazon DSP 与领星 ERP 请先核实账户内当前可用表，再安排分析。

Schema 是什么？需要懂数据库才能用吗？+

Schema 就是数据字典：有哪些表、包含什么字段、一行代表什么。你可以直接用自然语言提问；Schema 用来确认销售、广告或库存数据是否可用，以及指标应该如何理解。

已经有官方 MCP，为什么还要用 Hologrow？+

官方 MCP 可以很好地服务其所属平台。Hologrow 聚焦支持的数据源之间共享、持续同步的经营数据层，并提供可查的 Schema 与数据新鲜度。选择时，看你需要的是单个平台操作，还是跨来源经营分析。

数据多久更新？能看多久的历史？+

数据定期同步，不承诺实时。首次同步和历史回填因来源与数据表而异，也受上游报告延迟影响。比较前请在 Data Explorer 检查最近成功同步时间及可用数据的起止日期。

Claude 会修改出价、商品或库存吗？+

Hologrow MCP 仅提供只读访问，不发布内容、不出价、不修改源账户设置。Claude 可以帮助分析与整理建议，修改由团队审核后在对应工具中执行。

如何撤销 AI 访问或断开数据源？+

在 AI Platforms 撤销 OAuth 会话或轮换 MCP 密钥，可以停止 AI 访问。断开数据源是另一个操作：在 Integrations 断开后，Hologrow 会停止该账户同步并立即删除其已同步数据。

这些回答能直接证明利润或支持加预算吗？+

必须先有足够的数据依据。利润还需要成本、费用、退款与核实后的映射；不完整周期、缺失成本和不同归因窗口都应明确说明。本页对话使用虚构数据展示分析方式。
