阅读产品文档
可以把哪些数据带入 Claude？+

持续同步的数据源包括 Amazon Seller、Amazon Vendor、Amazon Ads、Google Ads、GA4、Google Search Console 和 Shoplazza。Shopify、Meta Ads、Amazon DSP 与领星 ERP 的覆盖已开放或仍在扩展，请以账户中 Data Schema 实际可用的数据表为准。

支持 Claude 网页版、桌面版和 Claude Code 吗？+

支持。Claude 网页版和桌面版使用连接器授权流程；Claude Code 使用托管 MCP 地址和 MCP 密钥。你的 Claude 套餐与工作区权限需要允许添加连接，请按对应文档操作。

Hologrow 会修改我的业务账户吗？+

不会。Hologrow 读取已同步数据，不修改出价、预算、商品、库存或源账户设置。分析和建议由你的团队审核。

数据多久更新？+

Hologrow 定期进行增量同步并回填历史数据。报告何时可用取决于数据源、账户和数据表。比较不同时段前，请在 Data Explorer 检查最近成功同步时间及覆盖日期。
