07 / QUESTIONS, ANSWERED

Gemini CLI integration FAQ

Connection details, practical workflows and what to verify before your first analysis.

Is Hologrow an MCP server for Gemini CLI?

Yes. Gemini CLI acts as the MCP client and reads synchronized data from Hologrow’s hosted server. This page does not describe exposing Gemini CLI itself as an MCP server.

Does this setup also apply to the Gemini web app?

No. The guide is specifically for the installed Gemini CLI. Do not assume that Gemini web or mobile has the same MCP configuration or access path.

Which authentication method should Gemini CLI use?

Hologrow’s current Gemini CLI guide specifies API-key authentication with an Authorization Bearer header. Create the MCP key in AI Platforms and use the native CLI configuration.

Can I reuse a prompt for a weekly review?

Yes. Make the dates, account, metrics, output format and missing-data checks explicit. Reusing a prompt does not remove the need to verify source coverage on each run.

Will Hologrow schedule Gemini CLI for me?

Hologrow synchronizes supported data sources. Scheduling the CLI, keeping its environment available and storing credentials securely are separate responsibilities of your workflow setup.

Why check cost_micros before calculating CPA?

Google Ads can represent cost in micros. Convert it to the account currency amount before dividing by the chosen conversion metric, and keep the conversion definition consistent.

Can the CLI optimize ads automatically through Hologrow?

It can help prepare analysis and review recommendations. Hologrow’s MCP access is read-only and does not apply campaign, keyword or budget changes.

What should the workflow do when dates are missing?

Report the unavailable period and stop the affected comparison or explicitly narrow its scope. Do not silently treat a missing day as zero performance.
