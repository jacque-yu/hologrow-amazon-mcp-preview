Hologrow 如何把经营数据接入 ChatGPT？

自定义 MCP 插件让 ChatGPT 在授权后读取 Hologrow 数据。先在 Hologrow 连接源账户，插件再提供当前用户可访问的已同步数据。

这里介绍的是 ChatGPT 网页版还是手机版？

这里对应浏览器中的 chatgpt.com，需要 Developer mode 与自定义 MCP app 权限，不是手机 app 的设置流程。

为什么看不到 Developer mode 或 Plugins？

请检查套餐与工作区角色。受管理的工作区可能需要管理员创建或允许该 app，Hologrow 无法开启你的 ChatGPT 账户尚未具备的功能。

每次复盘还需要上传 CSV 吗？

已通过 Hologrow 连接并同步的数据表，可以由 ChatGPT 经 MCP 查询。数据源之外的补充背景，仍需另行提供或维护。

能在一个问题中结合 Amazon 与 Google Ads 吗？

相关账户和表可用时可以。应要求明确日期与定义后并列比较；同步变化本身不能证明跨渠道归因或因果关系。

ChatGPT 每次回答都会实时访问源平台吗？

不会。Hologrow 提供已同步数据。分析未结束的一天或新连接账户前，应在 Data Explorer 检查最近成功同步与可用日期。

ChatGPT 可以通过这个连接器调整预算吗？

Hologrow 为只读访问。ChatGPT 可以帮助找出待复核的广告活动，但 Hologrow 不会向源平台写回预算、出价或店铺设置变更。

怎样取消 ChatGPT 的访问？
