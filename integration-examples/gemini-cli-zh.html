01 / 连接步骤

为 Gemini CLI 添加 Hologrow MCP server。

准备已安装并登录的 Gemini CLI，以及 MCP key。这里是让 Gemini CLI 作为客户端访问 Hologrow 的托管数据服务。

  1. 01

    选择数据并创建 key

    在 Hologrow 连接经营账户并确认可用日期，到 AI Platforms 创建用于 CLI 配置的 MCP key。

  2. 02

    使用原生 MCP 配置

    复制指南中的 Gemini CLI 安装提示词，在私有配置过程中替换 key 占位符。配置使用 Streamable HTTP 与 API key 授权，不使用 OAuth。

  3. 03

    分析前验证连接

    在 Gemini CLI 发送提示词，完成安装与已连接平台检查。先解决配置或授权错误，再开始数据查询。

03 / 为什么用 HOLOGROW

保留终端工作流，把重复的数据准备交出去。

Hologrow 管理支持来源的同步，你来定义 Gemini CLI 复盘如何运行。

自行准备数据

  1. 01为每个平台分别维护取数脚本与源平台凭据。
  2. 02比较已经完成，才发现报告周期不完整。
  3. 03更换客户端后，又重建一遍数据准备流程。

通过 HOLOGROW

  • 通过一个 Hologrow MCP 地址，访问账户中已同步的支持来源。
  • 在分析步骤之前，先核对可用日期与同步状态。
  • 在 Gemini CLI 与其他支持的 AI 客户端之间复用同一数据层。

07 / 常见问题

Gemini CLI 集成常见问题

连接方式、实际工作流程，以及首次分析前需要核实的内容。

Hologrow 是 Gemini CLI 可连接的 MCP server 吗？

是。Gemini CLI 作为 MCP 客户端，读取 Hologrow 托管服务中的已同步数据。本页不是介绍把 Gemini CLI 本身封装成 MCP server。

这套设置也适用于 Gemini 网页版吗？

不适用。这份指南针对已安装的 Gemini CLI，不应假设 Gemini 网页版或移动端具备相同的 MCP 配置与访问路径。

Gemini CLI 应使用哪种授权方式？

Hologrow 当前 Gemini CLI 指南指定 API key 授权，通过 Authorization Bearer header 使用。请在 AI Platforms 创建 MCP key，并采用 CLI 原生配置。

可以复用提示词做每周复盘吗？

可以。需要明确日期、账户、指标、输出格式与缺失数据检查。复用提示词不代表每次运行都可以省略覆盖范围验证。

Hologrow 会帮我定时启动 Gemini CLI 吗？

Hologrow 负责同步支持的数据源。CLI 定时启动、执行环境持续可用以及凭据安全保管，是工作流中需要另外配置的部分。

计算 CPA 前为什么要检查 cost_micros？

Google Ads 的成本可能以 micros 表示。除以所选转化指标之前，要先换算为账户币种金额，并保持转化定义一致。

CLI 能通过 Hologrow 自动优化广告吗？

可以帮助整理分析与复核建议。Hologrow MCP 为只读访问，不执行广告活动、关键词或预算变更。

日期缺失时，工作流应该怎么处理？

说明不可用的周期，停止受影响的比较，或明确缩小分析范围。不能默默把缺失日期当成零业绩。
